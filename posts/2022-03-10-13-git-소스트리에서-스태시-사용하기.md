소스트리 위쪽에 있는 스태시 클릭하여, 메시지 입력하고 확인을 누른다.

**스태시에 두었던 코드 다시 가지고오고 싶다면?**

오른쪽에 있는 스태시 탭에 해당 부분 오른쪽마우스!

**git bash에서 하는 방법**

1.Stash 생성 git stash 또는 git stash save 

2.Stash 리스트확인 git stash list 

3.Stash 적용 git stash apply 또는 git stash apply [stash이름] 또는 git stash apply --index
